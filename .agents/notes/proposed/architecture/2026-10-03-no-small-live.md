# Agent Note: 不设小额实盘阶段:dev2 只做测试网联调与模拟,正式实盘在统一升级主机上开始

Status: proposed

> **第八轮第四次修订(2026-10-03)**:补充——D 阶段切 Live 之前增加零成交冒烟 D-smoke 与正式实例 Shadow 3–7 天 D-shadow(不开仓,不算小额实盘);初始 `RiskParams` 上限与"第一次放宽"的条件是上线签字记录的必填数值(不是门槛);③④ 的累计改在服务器上;见 [shadow-before-live](../process/2026-10-03-shadow-before-live.md)、[verify-on-server](../process/2026-10-03-verify-on-server.md)。

## Problem

修订后的上线路径是"模拟账户 → 新子账户小额实盘(≥ 20 笔,单笔按最小名义)→ 逐步放量",小额实盘在 dev2 上进行——与旧系统正式账户共机、受 dev2 护栏约束。第二次独立评审指出三处互相牵制:门槛时序互锁(⑥ 中没有测试网的所由 ⑨ 的小额实单覆盖,而 ⑨ 排在后面);护栏停掉 hft-core 后不自动拉起,Broken 自动平仓随之停止;按最小名义设上限会放大两腿 lot 不对齐留下的残余([评审](../../../../design/_work/review-2026-10-03-M0b独立评审.md) P1-2、P1-6、P1-9,§4 第 1 条)。用户决定不跑小额实盘,只跑正式实盘与模拟盘([round8-decisions](../../../../design/_work/round8-decisions.md) R8-9 第 1 条)。

## Proposal

上线步骤归 [launch](../../../../docs/runbooks/launch.md);门槛归 [testing §8](../../../../docs/testing.md#8-上线门槛);升级步骤归 [host-upgrade](../../../../docs/runbooks/host-upgrade.md);部署护栏归 [deploy](../../../../deploy/README.md)。

1. **阶段**:A dev2 开发测试 + 三所测试网/模拟盘联调 → B dev2 上模拟账户连续 ≥ 14 天 → C 统一升级主机(prod + sim 同机;延迟验收用实时行情 + 测试网/模拟盘下单回路)→ D 正式实盘。没有小额实盘,也没有按档放量的阶段。
2. **dev2 不放正式实盘账户**:dev2 上常驻的 `sim` 实例只含 Sim 账户、不持 key;测试网联调时另起的 `prod` 角色实例 refdata 只含测试网账户,只在联调窗口运行。部署侧机械保证:dev2 的主机角色只能读测试网秘密前缀,预检拒绝指向正式端点的 Live 账户。
3. **门槛**:删除"小额实盘"一项;正式实盘前 ①–⑧、⑩、⑪ 全部满足;③④ 的累计量只卡正式实盘,不卡模拟。
4. **风险上限**:正式实盘的上限由运营在 `RiskParams` 设定;建议从保守值起步,这只是建议,不是门槛。
5. **校准**:同参数的模拟实例在 sim 实例上与正式实盘并行运行,用实盘结果校准模拟。

## Alternatives considered

**保留小额实盘,在 dev2 上设名义上限(评审给出的修法之一)。** 用户否决。dev2 上的实盘让护栏与实盘可用性互相牵制,最小名义的切片又放大 lot 残余。

**在升级主机上先小额、再按档放量。** 用户的决定是只有模拟与正式两种;"从保守限额起步"保留为运营建议,因为放量节奏取决于资金与行情,不是工程门槛。

**用测试网长跑代替模拟账户。** 测试网的行情与流动性不是真实市场(各所测试网行情来源待核实),评估不了策略;测试网只用来验证交易所接口与 kill 链路。

## Acceptance criteria

- 规格中(testing §8、launch、11 章、cookbook、hft-sim)没有"小额实盘""新子账户小额"字样,`check_hft.py` 机检通过。
- dev2 的 refdata 里没有指向正式端点的 Live 账户;以 dev2 主机角色读取正式秘密前缀被 IAM 拒绝(演练记录)。
- 首个正式账户切 Live 前,上线记录逐项列出 ①–⑧、⑩、⑪ 的证据链接。

## Risks

- 正式实盘的第一笔就是运营设定的规模:测试网覆盖不到真实流动性与真实费率;由模拟账户 ≥ 14 天、"单边 +30%"压力用例与保守起步的建议缓解。
- 各所测试网/模拟盘的可用性与 API 覆盖待核实;某所没有可用环境时 ⑥ 如何满足由 testing §8 规定。
- ③④ 在免费 CI 额度下到达需要数月,正式实盘的日历时间随之推后([ci-free-hosted](2026-10-03-ci-free-hosted.md))。
