# Agent Note: 同批恢复对冲预留

Status: implemented

## Problem

旧 main 7442aaf1 的 storage 种子 0x7442aaf1b5dea253 在原始 10000 步配置下于 1631 步违反 I19。同次恢复回调生成三笔 SecondRetry,后两笔没有剩余裸量。报告的 1632 步命令改变了依赖总步数的崩溃计划,无法复现。

## Decision

计算裸量时扣除当前 OmsOut 中同组同方向的未发送请求,按当前计划转换单位。失败结构保存原始步数,报告使用该步数。固定真实引擎种子运行 10000 步。

## Alternatives considered

只依赖风险检查会把错误请求推到下游。只缩短复现步数会改变故障计划,不能证明修复。

## Consequences

在独立归档的旧版本只应用数量预留修复后,原始种子 10000 步通过。新代码另覆盖三链接同批恢复与 journal 确定性。资金/恢复语义待评审,负责人默认接受。
