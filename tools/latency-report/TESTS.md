# latency-report 验证

扩展既有验收项，不分配新的冻结用例编号。

| 用例 | 行为 |
|---|---|
| RT-002 | 环满不阻塞，保留 FIFO、serial 缺口与最终 dropped |
| RT-166 | 启用记录后的循环仍为零分配 |
| NET-125 | 一个 read 内多个短/长帧关联 ID 各异，保留共同 RX 戳、解密戳、recvmsg pre/post 与每次 next_frame 独立开始戳 |
| NET-152 | 发送短写及后续 flush 保留同一密文区间，不依赖残留线程上下文 |
| VEN-199 | SendReport 不因测量而重复或改变，订单发送语义保持 |
| VEN-068 | raw 序号与 frame 关联在真实 journal 读回后吻合，不以同读时间猜匹配 |
| SEQ-053/054 | 测量不进入状态/输出哈希，不改变回放比较 |
| CORE-012 | 非法容量在 --check 拒绝；默认关闭 |
| CORE-220 | 干净停止后测量文件非空、记录对齐、serial 递增、completion 已关闭 |
| RPL-203 | 同 TLS 记录后续帧的前序处理等待不计入解帧；旧 trace 不虚构调用边界；读取按批次计数，首末 SW 跨度与最后读间隔分列；sendmsg pre 缺失不生成零耗时样本 |
| RPL-203 | 接收拆分按交付帧计权，多事件不重复；首末 SW 跨度、末读到交付与逐样本和可核对；无校准仍保留同钟域跨度，缺失末读或 FrameTiming 留空，负跨度单列 |
| RPL-203 | 多行批次逐行输出不变，所需列每批只物化一次；seq 非白名单列不读取，raw 只导出时间叶子 |
| RPL-203 | 逐事件 CSV 与分位数一致；MD-only、多 fill、丢失、歧义和负间隔显式报告；同 slot/gen 的不同 venue/account 回报不得串单，缺身份不关联；SW 前后校准插值、无 PHC 时的 REALTIME 速率误差、缺锚点/Stepped/超界过滤；跨段重复时钟载荷合并并计数，同戳冲突拒绝 |
